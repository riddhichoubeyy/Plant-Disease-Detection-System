# Plant Disease Detection System

Deep learning-based plant disease detection using CNN models and leaf images.

### Features

* Crop classification
* Healthy/diseased detection
* Disease classification
* Supports Bell Pepper, Potato, and Tomato

### Models

EfficientNet, ResNet50, VGG19, GoogLeNet, and AlexNet.

### Dataset

24,101 leaf images from PlantVillage and AI-Hub.

### Technologies

Python, TensorFlow, Keras, CNN, Transfer Learning.
